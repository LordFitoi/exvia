Foundations

Color, type, space

The tokens every component is built from. They mirror the Minimals design system, so a token here maps one to one to a token in Minimals and, later, to the Tailwind theme of the frontend.

Color

Always use tokens, never raw hex values. Fills use the main shade. Text and icons that carry meaning use --color-*-text: the dark shade on light surfaces (darker for success and warning) and the light shade on dark ones, which keeps them above 4.5:1 on their soft tints. White on main primary green is 3.1:1 (3.2:1 on error). That is how Minimals ships it, so keep those labels 15px bold, or set --color-on-primary to --color-grey-800 (5:1) when AA is required.

Typography

Public Sans for interface text and Barlow for the display headings (h1 to h3), both vendored in fonts/ under the SIL Open Font License so the guide works offline. Sizes are the Minimals mobile sizes in rem. The app column is capped at 30rem, so they do not grow with the viewport. Input text is never smaller than 1rem.

Spacing, radius and elevation

Spacing follows a 4px base and the Law of Proximity: 8px inside a group (label and field, heading and content), 16px between siblings, 24px between related blocks and 32px between groups. Prefer gap over margins. Screens have a 16px side gutter.

Shadows are grey in light mode and black in dark mode. Tint (hover, soft, outline) is the color at 8%, 16% and 48%.

Iconography

24px outline icons with a 2px stroke, rendered as CSS masks so they inherit currentColor. Mark decorative icons aria-hidden="true"; icon-only buttons need an aria-label. Use conventional glyphs only (Mental Model).
