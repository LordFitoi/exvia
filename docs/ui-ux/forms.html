Ask less, guide more

Fields, menus and the patterns that keep long forms easy: chunking, progressive disclosure and a visible sense of progress.

Inputs

Minimals outlined fields, 56px tall. Labels stay visible above the field and placeholders are examples, never labels. Accept any reasonable format (Postel): trim spaces, ignore case, allow dashes in phone numbers. Errors say how to fix the problem and appear below with aria-invalid and aria-describedby.

Select, dropdown and suggestions

Prefer the native select on mobile: it opens the OS picker. Use the custom dropdown for short lists (7 options or fewer) that need rich rows. Group longer lists, and preselect the common choice. When the answer is a name the person types (a rider's username), complete it with suggestions under the field instead of a list to scroll.

Forms and steps

Split long forms into fieldsets of 3 to 4 fields (Chunking). Fields sit 16px apart and fieldsets 32px apart (Proximity). Fold optional fields in a disclosure (Tesler). In a multi-step flow, say where the person is and how much is left (Goal-Gradient). Set --progress (0 to 1) per instance.
