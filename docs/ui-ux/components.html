Controls

Building blocks

Each component is a reusable class (BEM-light, hyphenated). Variants add a modifier class; states use ARIA attributes (aria-pressed, aria-selected, aria-current, aria-invalid).

Buttons

Minimals buttons: 8px corners and a bold label. A tone (button-primary, button-error) picks the color and a variant (button-soft, button-outline, button-text) picks the fill, so they combine. Use one filled button per screen for the key action (Von Restorff, Occam). Everything else is soft, outlined or text. The default is 48px tall and at least 120px wide (Fitts).
